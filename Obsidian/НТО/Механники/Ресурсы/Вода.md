##  Основная информация 

Вода - это один из 3 ресурсов. Он нужен для выживания [[Персонажи|людей]]

Каждый [[Персонажи|человек]] потребляет фиксированное количество воды в [[Дни|день]]. Количество воды, потребляемое [[Персонажи|персонажем]], генерируется случайно в самом начале игры, за это отвечает [[Скрытые параметры#Скорость наступление жажды|параметр скорости наступление жажды]]. Одна из важнейших задач игрока - сохранять достойное количество воды для выживания колонии. В [[Начало игры|начале игры]] уже есть определенное количество воды.

Для удобства можно представить, что каждый человек - стакан, с которого пьют воду каждый день. Игрок же может доливать воду в стакан, из всех запасов.

Варианты для наливания воды:
- Дать немного воды (15 единиц)
- Дать среднее количество воды (25 единиц)
- Дать сполна (40 единиц)
- Максимально

Напоить человека можно **несколько раз в [[Дни|день]]**, его показатели сразу изменятся. Но на следующий день они опять уменьшаться

## Поломка водопровода

Система подачи воды нестабильна, иногда она может сломаться. Тогда целый [[Дни|день]] будет ***невозможно*** выдавать воду [[Персонажи|людям]]!

Шанс поломки зависит от количества [[Персонажи|людей]]. [[Начало игры|Изначально]] у игрока **5** людей. За всю игру больше людей быть не может

**Таблица шансов**

| Кол-во людей | Шанс на поломку |
| ------------ | --------------- |
| 5            | 35%             |
| 4            | 30%             |
| 3            | 25%             |
| 2            | 20%             |
| 1            | 15%             |
