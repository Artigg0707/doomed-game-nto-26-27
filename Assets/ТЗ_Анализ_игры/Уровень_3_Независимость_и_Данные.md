## 1. Независимость модулей

Модули игры уже слабо связаны через:
- **Singletons с `Instance`** — каждый менеджер доступен глобально, но не жёстко привязан к конкретному экземпляром другого менеджера (ищется через `FindObjectOfType` / `GetComponent` при отсутствии ссылки).
- **События `Action`** — `OnResourcesChanged`, `OnRationsChanged`, `OnExpeditionsChanged`, `OnNightComplete`, `OnDayChanged`, `OnDefeat`, `OnVictory` позволяют модулям реагировать друг на друга без прямых ссылок.
- **Интерфейсы `IInteractable`, `IHighlightable`, `IOpenablePanel`** — объекты мира и UI взаимодействуют через контракты, а не конкретные классы.

**Что дополнительно сделано на уровне 3:**
- `GameBalanceConfig` вынесет все числовые параметры из кода managers в данные. Менеджер не знает конкретных значений баланса — он читает их из конфига.
- Новые элементы (локация, черта, записка) добавляются **только через `.asset`-файлы**, без изменения любого `.cs`-файла.

## 3. Инструкция: как добавить новый элемент через данные

### Шаг 1. Создайте `.asset`-файл нужного типа
В Unity: **ПКМ в окне Project → Create → Game/[тип]** (или вручную через текстовый YAML, как сделано здесь).
- Для локации: `Game/Expeditions/Location` → `ExpeditionLocationData`
- Для черты: `Scriptable Objects/Trait` → `Trait`
- Для записи: `Door Note` → `DoorNoteData`

### Шаг 2. Заполните поля в инспекторе
Пример заполнения для каждой категории — см. раздел 4 («Исходный и изменённый варианты данных»).

### Шаг 3. Зарегистрируйте элемент в соответствующем контейнере (если требуется)
- **Локация**: добавьте ссылку на новый `.asset` в `ExpeditionLocationCatalog.locations`.
- **Черта**: добавьте ссылку на новый `.asset` в `CharaterObject.availableTraits`.
- **Записка**: достаточно положить `.asset` в любую папку `Resources/` — `EventManager` подхватит её автоматически через `Resources.LoadAll<DoorNoteData>("")`.

### Шаг 4. Проверьте в игре
- Запустите сцену `GameScene 1`.
- Локация появится в списке вылазок.
- Черта может выпасть у нового персонажа при генерации.
- Записка может выпасть случайно (шанс 25% в день) или по расписанию.

### 4.2 Черта персонажа: Инженер

**До:** `CharaterObject.availableTraits` был пуст (`[]`). Персонажи генерировались без черт.

**После:** добавлена черта «Инженер» со эффектами:
- `ElectricityBreakChanceChangePoints` = −10 (снижает шанс поломки генератора)
- `ElectricityRepairInjuryChanceReductionPercent` = −15 (снижает шанс травмы при ремонте)

Файл `ScriptableObjects/Definitions/EngineerTrait.asset` (новый):

```yaml
traitName: "Инженер"
traitDesc: "Снижает шанс поломки генератора и вероятность травмы при ремонте."
category: 0  # Positive
effects:
- effectType: 2   # ElectricityBreakChanceChangePoints
  value: -10
- effectType: 11  # ElectricityRepairInjuryChanceReductionPercent
  value: -15
```

**Изменение в `CharaterObject.asset`:**
```yaml
# Было: availableTraits: []
# Стало:
availableTraits:
- {fileID: 11400000, guid: f1e2d3c4b5a697887766554433221100, type: 2}
```

**Как выглядит в игре:** при генерации персонажа (`CharacterGenerator.Generate()`) с вероятностью 1/N (где N — число черт в профиле) новый житель получает черту «Инженер». Ночью при работе генератора (`ElectricalPanelController.CalculateBreakdownChance`) шанс поломки снижается на 10 пунктов; при ремонте генератора шанс травмы снижается на 15%.

### 4.3 Записка у двери: Гуманитарная доставка

**До:** только одна запланированная записка (`DoorNoteData.asset` с `triggerDay: 2`).

**После:** добавлена случайная записка «Гуманитарная доставка» с шансом 25% в любой день.

Файл `Resources/DoorNote_SupplyDrop.asset` (новый):

```yaml
spawnType: 1  # Random
title: "Гуманитарная доставка"
text: "У дверей в бункер оставили гуманитарный конвой. Выберите один из вариантов."
triggerDay: 0
randomChance: 25
morningReportLine: "О гуманитарной доставке сообщили утром."
options:
- buttonText: "Взять еду и воду"
  deltaFood: 5
  deltaWater: 5
  deltaFuel: 0
  deltaMorale: 10
  hpDamage: 0
  spawnCharacterChance: 0
- buttonText: "Взять топливо"
  deltaFood: 0
  deltaWater: 0
  deltaFuel: 3
  deltaMorale: 5
  hpDamage: 0
  spawnCharacterChance: 0
```

**Изменений в существующих файлах не требуется** — `EventManager.Start()` вызывает `Resources.LoadAll<DoorNoteData>("")` и подхватывает новый ассет автоматически.

**Как выглядит в игре:** в случайный день (шанс 25%) у двери появляется записка с двумя вариантами ответа. Игрок выбирает → `EventManager.ApplyOption()` применяет дельты ресурсов/морали. Событие отражается в утренней сводке.
