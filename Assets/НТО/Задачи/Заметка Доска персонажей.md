# 📋 Доска персонажей (CharacterBoard)

## Иерархия сцены
```
доскаканвас (Canvas World Space)
├── CardContainer (пустой RectTransform, БЕЗ LayoutGroup)
└── BioPanel (скрыта)
    ├── Header (перетаскивание только за него)
    └── Bio Scroll View → Content
```

## Скрипты
- `CharacterBoard.cs` — спавн карточек, управление списком, клик → биография
- `CharacterCardUI.cs` — данные на карточке (портрет, имя, возраст, черта, секрет)
- `CharacterCardDrag.cs` — перетаскивание карточки (уже есть)
- `CharacterBioPanel.cs` — одна панель биографии, показывает данные, закрытие, перетаскивание за Header

## Логика
- При старте: для каждого `CharacterManager.characters` создать карточку
- Случайная позиция внутри CardContainer (с защитой от наложения карточек)
- Клик без драга (порог ~15 px) → открыть/обновить BioPanel
- Перетаскивание карточки не открывает биографию
- BioPanel одна на все карточки (обновляется данными, не дублируется)

## Критерии готовности
- [ ] 5 персонажей = 5 карточек
- [ ] Карточки внутри границ, случайные позиции
- [ ] Клик открывает биографию, драг — нет
- [ ] Нажатие на другую карточку обновляет ту же панель
