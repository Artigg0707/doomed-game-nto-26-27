# ПК и интерфейс управления

## 1. Роль ПК

ПК — центральный интерфейс управления важными действиями. Через него игрок не просто смотрит информацию, а принимает решения, которые определяют следующий ночной расчёт.

ПК нужен для:

- запуска экспедиции;
- назначения работ;
- просмотра занятых персонажей;
- приказов и изгнания;
- просмотра предупреждений;
- контроля активных заданий.

ПК не должен заменять всю игру. Распределение пайков остаётся отдельным взаимодействием, а записки открываются у двери.

## 2. Вкладки ПК

```text
ПК
├── Экспедиции
├── Работы
├── Приказы
└── Сводка
```

### Вкладка «Экспедиции»

Показывает:

- список локаций;
- уровень опасности;
- возможный лут;
- рекомендуемые профессии;
- выбранных участников;
- кнопку «Отправить»;
- активные экспедиции.

### Вкладка «Работы»

Показывает задания, созданные состоянием бункера:

- починить генератор;
- починить водопровод;
- отдых в лазарете;
- дежурство;
- подготовка к особому событию.

Каждая работа должна показывать:

- проблему;
- последствия бездействия;
- доступных персонажей;
- ожидаемый результат;
- риск провала или травмы.

### Вкладка «Приказы»

Содержит решения, которые нельзя случайно нажать:

- изгнать персонажа;
- отменить назначение;
- подтвердить рискованный приказ;
- открыть список последствий.

Изгнание обязательно требует подтверждения:

> «Изгнать этого человека? Он покинет бункер навсегда. Мораль остальных снизится».

### Вкладка «Сводка»

Показывает текущую ситуацию:

- день;
- еда;
- вода;
- топливо;
- температура;
- живые жители;
- свободные жители;
- активные работы;
- активная экспедиция;
- неразрешённая записка.

## 3. Состояния персонажа на ПК

Каждый персонаж должен иметь один статус:

- «Свободен»;
- «На экспедиции»;
- «Чинит генератор»;
- «Чинит водопровод»;
- «На дежурстве»;
- «Отдыхает»;
- «Ранен»;
- «Мёртв»;
- «Ушёл».

Кнопка назначения должна быть недоступна, если персонаж уже занят.

## 4. Подтверждение действий

Перед важным действием ПК показывает:

- кого игрок отправляет;
- что он больше не сможет делать;
- когда будет результат;
- какой риск существует.

Пример:

> «Алексей будет отсутствовать до утра. Он не сможет чинить генератор сегодня. Отправить его на ТЭЦ?»

## 5. Условия завершения дня

ПК не должен сам переводить игру в ночь. Сон всегда запускается через кровать.

Перед сном ПК может показывать предупреждение:

- генератор сломан;
- работа не назначена;
- записка требует решения;
- персонаж остался без пайка;
- экспедиция уже отправлена.

Предупреждение не должно молча исправлять проблему за игрока.
