# 🌙 DayCycleManager — игровой цикл день/ночь

## Состояния (FSM)
1. `Morning` — утренняя сводка (автооткрытие окна отчёта)
2. `Day` — дневное управление (игрок в комнате, может ходить по точкам)
3. `Night` — ночной переход (игрок ложится в кровать)

## Поля
```csharp
public int currentDay; // 1..10
public DayPhase currentPhase;
public bool gameEnded;
```

## Ночной расчёт (переход Day → Night)
1. Потратить 1 канистру топлива (если генератор работает и топливо > 0)
2. Если топлива 0 или генератор сломан → температура −1 уровень
3. Для каждого жителя:
   - Если дней без еды == 0 и не накормлен сегодня → daysWithoutFood++
   - daysWithoutFood == 1 → мораль −10
   - daysWithoutFood >= 2 → HP −25, мораль −20
   - Аналогично с водой (−15 мораль, −40 HP, на 3-й день без воды смерть)
4. Проверка смертей (HP ≤ 0)
5. Возвращение экспедиции (лут, ранения, смерть)
6. Утренний конверт слежки (если был шпион)
7. Проверка концовок: день == 10 и есть живой → Победа; живых == 0 → Поражение

## UI
- Утренняя сводка (панель с текстом результатов ночи)
- Кнопка «Закрыть отчёт» → переход к фазе Day

## Критерии готовности
- [ ] Игра переключает дни 1→2→3...→10
- [ ] Ночь тратит ресурсы и наносит урон персонажам
- [ ] Победа/поражение срабатывают корректно
