# Точка взаимодействия: Водопроводные трубы (Water Pipes)

Ржавый водопроводный узел с манометрами, фильтрами и кранами раздачи питьевой воды.

---

## 1. Взаимодействие в 3D
- При наведении курсора трубы выделяются [[Обводка|обводкой]].
- Если произошла авария — из стыка с шипением валит пар/вода, раздается свист.
- Подсказка: `[E] Проверить водопровод`.

---

## 2. Интерфейс 2D-окна:

### Штатный режим (Водопровод исправен):
- Счетчик запасов: «На складе: X канистр [[Вода|воды]]».
- Список жителей с кнопками `[Выдать канистру]`.
- Индикаторы статуса жажды для каждого человека:
  - «Напоен» (зеленый)
  - «Испытывает жажду» (желтый)
  - «Обезвожен (-40 HP)» (красный мигающий)

### Аварийный режим (Прорыв трубы):
- Подача воды заблокирована красным предупреждением: *«АВАРИЯ: Засор фильтра / Прорыв стыка!»*.
- Кнопка `[Назначить человека на починку]`:
  - Выбор ремонтника для выполнения задачи [[Починка водопровода]].
  - Если выбран [[Особенности персонажей#Сантехник|Сантехник]] — поломка устраняется мгновенно и безопасно.
